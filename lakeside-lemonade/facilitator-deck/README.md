# Facilitator debrief deck

Source files for the 19-slide debrief deck (one section per module), published at
https://claude.ai/artifact/3zUzofG14jNKJiqALxRa8g — present it there or download it as
PowerPoint/PDF. `deck.json` is the index; `slides/<id>.html` holds each slide and its
speaker notes (the `<aside>`).
