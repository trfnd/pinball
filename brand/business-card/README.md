# Paw Tap digital business card

Built 2026-09-26 in the style of logo direction **A1, "The gentle drop"** (the black cat tapping an orange flipper). The mark in `paw-tap-mark.svg` is a simplified vector redraw for the card. It is a concept, not approved artwork.

| File | What it's for |
|---|---|
| `ibrahim-turfanda.vcf` | Contact card with the logo as the photo. Open it on the iPhone and tap **Create New Contact**. |
| `contact-qr.png` | QR code holding the same contact details (no photo). Someone scans it with the iPhone camera and saves you as a contact. |
| `paw-tap-card.png` | Image of the full card. Save to Photos to show or text someone. |
| `index.html` | The card as a web page (works offline, fonts embedded). Host it with the other files, e.g. at `pawtappinball.com/card`, and "Save to Contacts" downloads the `.vcf`. |
| `apple-touch-icon.png` | Home Screen icon used when the hosted page is added to the Home Screen. |

## Using it on an iPhone

1. **Your own contact card.** AirDrop or email `ibrahim-turfanda.vcf` to yourself, open it, and save it. In Contacts, set it as **My Card** (Settings › Contacts › My Info). Then NameDrop (hold two iPhones close together) and Contacts › Share Contact both send it.
2. **Show the QR code.** Save `contact-qr.png` to Photos and add it to a Favorites album, or add a Photos widget to the Home Screen, so you can pull it up fast.
3. **Link version.** After `index.html` is hosted, open it in Safari and use Share › Add to Home Screen. Texting the link works for people who aren't nearby.
